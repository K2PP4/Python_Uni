# Repo per la gestione degli esercizi e/o appunti

## Corso: INFORMATICA E LABORATORIO DI PROGRAMMAZIONE
## Laurea: Triennale - Ingegneria delle Tecnologie Informatiche (LINTINF)

---

## 📌 Descrizione
Questo repository raccoglie esercizi, codice sorgente e/o appunti relativi al corso di **Informatica e Laboratorio di Programmazione** per il corso di laurea triennale in **Ingegneria delle Tecnologie Informatiche (LINTINF)**.

## 📂 Struttura del Repository
Il materiale è organizzato indicativamente in questo modo:
* **esercizi**: Raccolta delle esercitazioni pratiche svolte durante il corso.
* **appunti**: Note teoriche e riassunti utili per lo studio.
* **codice**: Script, progetti ed esempi di codice.
